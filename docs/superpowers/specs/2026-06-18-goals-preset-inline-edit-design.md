# 目標：プリセット4件＋直接書き換え（＋・鉛筆を廃止）設計書

作成日: 2026-06-18

## 目的

目標の追加に使う「＋ボタン」が面倒。デフォルトで4件のプリセットを入れ、タップして直接書き換えられるようにすることで＋ボタンと鉛筆（編集モード切替）を廃止し、操作を最小化する。

## デフォルト目標（保存が無い日に表示）

1. 深く呼吸する、紙に書く
2. 未来の自分との約束を守る
3. だから優先順位を守る
4. 全てに感謝します（4件目＝スクロールで表示）

## 操作仕様

- 常に4行固定。各行＝丸チェック（完了トグル）＋常時編集できるテキスト入力（タップして上書き）。
- ＋ボタン廃止。今日の目標セクションの鉛筆（編集モード切替）も廃止。
- 今日の言葉・COMING UP の鉛筆は従来どおり維持。
- 行削除（ゴミ箱）は無し。消す時は文字を空にする（空欄はプレースホルダー「目標 N」）。
- 3件表示＋4件目スクロール（`max-h-[176px]`）は維持。
- 丸チェックで完了トグル（完了は打ち消し線＋淡色）。完了行も編集は可能。

## データの扱い

- `DEFAULT_GOALS` 定数（id: "1".."4"、上記テキスト、completed:false）。
- 初期 state の goals は `DEFAULT_GOALS` のコピー。
- 読み込み時：その日（dateKey）の保存があれば使用、無ければデフォルト。今日の言葉と同じく毎日リセット。
- `normalizeGoals(arr)`：常に4枠を返す。`arr[i]` があればその text/completed を使い、無い枠だけデフォルトで補完。空文字は空のまま尊重。古い保存（件数違い）でも崩れない。

## 廃止・変更するコード

- `isEditingGoals` state、目標セクションの鉛筆/保存ボタン、`addEmptyGoal`、＋ボタンJSX、`deleteGoal`、編集モード分岐を削除。
- 目標行は常時 `<input>`（編集モード分岐なし）。`editGoalText`・`toggleGoal` は維持。
- 読み込み・初期化で `normalizeGoals` を通す。
